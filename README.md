# دارفانت

دارفانت یک برنامهٔ فارسی برای ویندوز ۶۴ بیتی است که بر پایهٔ v2rayN 7.25.6 ساخته شده است.

نسخهٔ ۱.۱ رابط مستقل و جمع‌وجور دارفانت را دارد. پنجرهٔ اصلی از عرض ۳۶۰ پیکسل پشتیبانی می‌کند و در ارتفاع کم اسکرول می‌شود.

[دانلود نسخهٔ ویندوز](https://github.com/topgsmir/Darfant/releases/latest/download/Darfant-windows-x64.zip) · [راهنمای فارسی](Darfant-fa.md)

همهٔ فایل‌های زیپ را استخراج کنید، سپس `Darfant.exe` را اجرا و درخواست دسترسی مدیر ویندوز را تأیید کنید.

- در نوار بالایی، «وارد کردن لینک» پس از تأیید آدرس، اشتراک را همان لحظه می‌گیرد. «به‌روزرسانی لینک» برای دریافت دستی است. اشتراک‌های فعال در زمان اجرای برنامه هر ۳۰ دقیقه تازه می‌شوند.
- «تست پینگ همگی» تأخیر سرورها را در همهٔ گروه‌ها می‌سنجد.
- از دکمهٔ مرکزی برای اتصال و قطع استفاده کنید. محدودهٔ وی‌پی‌ان را می‌توانید روی کل سیستم، مرورگرها یا برنامه‌هایی که انتخاب می‌کنید تنظیم کنید.
- اشتراک‌ها، تنظیمات و گزارش اتصال از منوی سه‌نقطهٔ بالای پنجره در دسترس هستند.
- دامنه‌های `.ir` و IPهای ایران در تنظیمات استاندارد و Clash مستقیم وصل می‌شوند. کانفیگ‌های کامل JSON با قواعد خودشان اجرا می‌شوند.

## ساخت نسخهٔ ویندوز

با .NET SDK 10 و PowerShell، بستهٔ اصلی [v2rayN-windows-64.zip از نسخهٔ 7.25.6](https://github.com/2dust/v2rayN/releases/tag/7.25.6) را کنار پوشهٔ مخزن بگذارید و از داخل مخزن دستور زیر را اجرا کنید.

```powershell
.\Build-Darfant.ps1
```

برای تعیین محل فایل اصلی یا پوشهٔ خروجی از گزینه‌های `-Bundle` و `-Output` استفاده کنید.
